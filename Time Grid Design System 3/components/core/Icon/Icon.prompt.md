Renders one glyph from Time Grid's 6-icon line set (month, day, hour, pie, chevronLeft, chevronRight) — use for module headers and nav controls, never decoratively.

```jsx
<Icon name="pie" size={18} />
```

Color follows `currentColor`/`--text-muted`; wrap in a colored parent to recolor. No fill variants — stroke-style line icons only.
