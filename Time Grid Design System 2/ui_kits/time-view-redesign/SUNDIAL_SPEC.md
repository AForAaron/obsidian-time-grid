# 日晷时间视图 · 原型评审规格

## 信息层级

1. 长期轨迹：3个月、6个月、1年切换，默认并记忆6个月。
2. 本月位置：过去、今天、未来保持同一套刻度语义。
3. 此刻日晷：外圈为今日24小时，内圈为当前60分钟，暖点为当前秒。
4. 当前计时：空闲、运行、切换、冲突、异常与跨日恢复都在日晷正下方完成。
5. 今日去向：比例条与列表陈述今日时间分布，不进行效率评价。

## 已锁定交互

- 空闲时可手输活动；最近7天活动、今日/逾期任务和今日流程均为一键开始快捷项。
- 任一时刻只允许一个运行活动。开始另一活动时，旧活动与新活动使用同一切换时刻。
- 任务只贡献活动名称，不改变任务状态；Task面板不增加入口。
- 无日记或无计时块时，开始动作会自动准备数据；原型仅模拟这一过程。
- 多个运行项必须显式“结束全部并继续”；错误JSON与多个计时块均拒绝写入。
- 跨日超过24小时必须确认，可补齐并继续、在首个午夜结束或暂不处理。

## 评审矩阵

| 维度 | 覆盖项 |
| --- | --- |
| 宽度 | 280 / 320 / 420 / 720px |
| 主题 | 深色 / 浅色 |
| 正常状态 | 空闲 / 运行中 / 刚刚切换 |
| 自动准备 | 无日记 / 无计时块 |
| 安全状态 | 多个运行项 / JSON异常 / 写入失败 |
| 恢复状态 | 跨日超过24小时 |
| 输入方式 | 手输 / 最近活动 / 任务 / 每日流程 |
| 无障碍 | 原生按钮与输入、键盘焦点、reduced-motion |

## 生产阶段边界

原型通过评审前，不修改 `src/`、Task面板或真实日记。生产实现只包含开始、停止、切换和跨日恢复，不包含暂停、历史编辑、批量管理、并行计时、命令面板或快捷键。
